# E-commerce Sales Analysis

## Overview

Projeto de análise de dados utilizando SQL em banco Oracle, com foco em métricas comerciais de um e-commerce fictício.

O objetivo foi explorar dados relacionais e responder perguntas de negócio comuns em contextos de Data Analyst / BI Analyst.

---

## Tools Used

- Oracle SQL
- SQL Developer
- Git / GitHub
- VS Code

---

## Database Structure

O projeto utiliza as seguintes tabelas:

- CLIENTES
- PRODUTOS
- CATEGORIAS
- PEDIDOS
- ITENS_PEDIDO
- PAGAMENTOS

---

## Business Questions Answered

1. Receita total da empresa  
2. Ticket médio dos pedidos  
3. Receita por categoria  
4. Top 5 clientes por valor gasto  
5. Top 5 produtos por faturamento  
6. Pedidos por mês  
7. Status dos pedidos  
8. Métodos de pagamento mais usados  
9. Produtos sem venda  
10. Clientes recorrentes

---

## Key Skills Demonstrated

- JOINs entre múltiplas tabelas
- GROUP BY e HAVING
- KPIs comerciais
- Agregações (SUM, COUNT, AVG)
- Análise relacional
- Organização de projeto com GitHub
